### Описание проекта    
Угадать загаданное компьютером число за минимальное количество попыток

:arrow_up:[ к оглавлению](#оглавление)


### Кейс    
Написать программу, которая угадывает число за минимальное количество попыток.

**Условия соревнования:**  
* компьютер задает случайное натуральное число от 0 до 100, которое нужно угадать;
* под _"угадать"_ подразумевается написать программу, которая угадывает число;
* алгоритм учитывает информацию о том, больше или   меньше случайное число нужного нам;
* начальные условия зафиксированы для воспроизводимости кода.

**Метрика качества**     
* результаты оцениваются по среднему количеству попыток при 1000 повторений;
* необходимо добиться минимального количества попыток (предел - 20 подходов).

**Что практикуем**     
* Учимся писать хороший код на _Python_.
* Учимся работать с _IDE_.
* Учимся работать с _GitHub_.


### Этапы работы над проектом  
Задание функций:
* для генерации случайного натурального числа в заданном диапазоне;
* для "угадывания" сгенерированного случайного числа с учетом информации о том, больше или   меньше случайное число угадываемого.


:arrow_up:[ к оглавлению](#оглавление)


### Результаты:  
Вывод среднего количества попыток, за которое написанный алгоритм угадывает число.

:arrow_up:[ к оглавлению](#оглавление)



### Выводы:  
Количество попыток можно минимизировать, если не просто рандомно угадывать число, а учитывать информацию о том, больше или меньше случайное число угадываемого, сужая итеративно диапазон возможных чисел после каждой попытки.
