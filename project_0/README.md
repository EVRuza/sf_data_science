### Описание проекта
Угадать загаданное компьютером число за минимальное количество попыток

:arrow_up:[ к оглавлению](#оглавление)

### Кейс
Написать программу, которая угадывает число за минимальное количество попыток.

**Условие соревнования:**
* компьютер закадывает целое число от 0 до 100, которое нужно угадать
* под "угадать" подразумевается написать программу, которая угадывает число
* алгоритм учитывает информацию о том, больше ли случайное число или меньше нужного нам

**Метрика качества**  
Результат оценивается по среднему количеству попыток при 1000 повторений

**Что практикуем**  
Учимся присать хороший код на python
